# 🛡️ Siber Güvenlikte Uzmanlık Alanları

Siber güvenlik tek bir meslekten oluşmaz.

Siber güvenlik içerisinde farklı uzmanlık alanları bulunur ve her alan farklı sistemlere, problemlere ve teknik bilgilere odaklanır.

Örneğin bir kişi ağ güvenliği üzerine çalışırken başka bir kişi web uygulamalarının güvenliği, mobil uygulamalar, dijital adli bilişim veya bulut güvenliği üzerine uzmanlaşabilir.

Bu nedenle siber güvenlik alanlarını öğrenirken temel kavramların yanında farklı uzmanlık alanlarının ne yaptığını da bilmek önemlidir.

---

# 🌐 1. Ağ Güvenliği

## Alan: Ne ile ilgilenir?

**Ağ Güvenliği (Network Security)**, bilgisayar ağlarının ve ağ üzerinden taşınan verilerin yetkisiz erişimlere ve tehditlere karşı korunmasıyla ilgilenir.

Örneğin:

* Kurumsal ağlar
* Sunucular
* Router ve switchler
* Firewall sistemleri
* VPN bağlantıları
* Ağ trafiği

ağ güvenliğinin çalışma alanına girebilir.

## Günlük olarak neler yapabilir?

Bir ağ güvenliği uzmanı:

* Firewall kurallarını inceleyebilir.
* Ağ trafiğini analiz edebilir.
* VPN yapılandırmalarını kontrol edebilir.
* Ağ segmentasyonunu değerlendirebilir.
* Şüpheli trafik davranışlarını araştırabilir.
* Ağ cihazlarının güvenlik ayarlarını kontrol edebilir.
* IDS/IPS sistemlerini izleyebilir.

## Hangi teknik bilgilere ihtiyaç duyar?

* TCP/IP
* IPv4 / IPv6
* DNS
* DHCP
* NAT
* Routing
* Switching
* VLAN
* Firewall
* VPN
* TCP / UDP
* Network monitoring

### Kısaca

> **Ağ Güvenliği = Ağları ve ağ trafiğini korumak.**

---

# 🛡️ 2. SOC / Mavi Takım

## Alan: Ne ile ilgilenir?

**SOC / Blue Team**, kurumun güvenlik olaylarını izleme, tespit etme, analiz etme ve savunma süreçleriyle ilgilenir.

Bu alan daha önce öğrendiğimiz:

* SOC
* SIEM
* Log
* Alert
* Incident
* Incident Response

kavramlarıyla doğrudan bağlantılıdır.

## Günlük olarak neler yapabilir?

Bir SOC Analyst:

* SIEM ekranlarını izleyebilir.
* Alertleri inceleyebilir.
* Log analizi yapabilir.
* Şüpheli girişleri araştırabilir.
* Kullanıcı aktivitelerini inceleyebilir.
* Güvenlik olaylarını sınıflandırabilir.
* Incident kayıtları oluşturabilir.
* Şüpheli davranışları araştırabilir.

Örneğin:

```text id="8hm3ml"
03:00 → Yurt dışından giriş
       ↓
SIEM Alert
       ↓
SOC Analyst
       ↓
Log analizi
       ↓
Normal mi?
       ↓
Incident mı?
```

## Hangi teknik bilgilere ihtiyaç duyar?

* Network temelleri
* Windows / Linux
* Log analizi
* SIEM
* Authentication
* Active Directory
* Endpoint Security
* MITRE ATT&CK
* Incident Response
* Threat Intelligence

### Kısaca

> **SOC / Blue Team = Saldırıları izlemek, tespit etmek ve savunmak.**

# 🕵️ 3. Sızma Testi

## Alan: Ne ile ilgilenir?

**Penetration Testing (Pentest)**, yetkilendirilmiş bir sistemin güvenlik açıklarını kontrollü şekilde değerlendirmeye yönelik çalışmalardır.

Amaç gerçek zarar vermek değil, güvenlik zayıflıklarını tespit etmektir.

## Günlük olarak neler yapabilir?

Bir pentest uzmanı:

* Web uygulamalarını test edebilir.
* Ağ servislerini değerlendirebilir.
* Kimlik doğrulama mekanizmalarını inceleyebilir.
* Güvenlik açıklarını araştırabilir.
* Yetkilendirme kontrollerini test edebilir.
* Bulguları raporlayabilir.
* Güvenlik açıklarının etkisini değerlendirebilir.

## Hangi teknik bilgilere ihtiyaç duyar?

* Network
* Linux
* Windows
* Web teknolojileri
* HTTP / HTTPS
* SQL
* Authentication / Authorization
* OWASP
* Güvenlik açıkları
* Scripting
* Temel programlama

### Kısaca

> **Pentest = Yetkili ve kontrollü şekilde güvenlik zayıflıklarını değerlendirmek.**

# 💻 9. Uygulama Güvenliği

## Alan: Ne ile ilgilenir?

**Application Security (AppSec)**, yazılım geliştirme sürecinin güvenlik açısından ele alınmasıyla ilgilenir.

Buradaki amaç güvenliği yalnızca uygulama tamamlandıktan sonra kontrol etmek değil, geliştirme sürecinin içine dahil etmektir.

## Günlük olarak neler yapabilir?

Bir AppSec uzmanı:

* Kod güvenliği kontrolleri yapabilir.
* Güvenlik açıklarını araştırabilir.
* Dependency güvenliğini kontrol edebilir.
* Code review süreçlerine katılabilir.
* SAST / DAST gibi güvenlik testlerini değerlendirebilir.
* Geliştiricilere güvenli kodlama konusunda destek olabilir.
* CI/CD süreçlerine güvenlik kontrolleri eklenmesine yardımcı olabilir.

## Hangi teknik bilgilere ihtiyaç duyar?

* Programlama
* Git
* Web teknolojileri
* API
* Secure coding
* OWASP
* CI/CD
* SAST
* DAST
* Dependency security
* DevSecOps

### Kısaca

> **Application Security = Yazılımın geliştirilmesinden çalıştırılmasına kadar güvenliği ele almak.**

* Olayı kontrol altına alma çalışmalarına katılabilir.
* Delilleri koruyabilir.
* Olay sonrası analiz yapabilir.
* Olay raporu hazırlayabilir.

## Hangi teknik bilgilere ihtiyaç duyar?

* Network

* Log analysis
* SIEM
* Endpoint Security
* Digital Forensics
* Threat Intelligence
* Malware
* Incident Response processes

# ⚙️ 12. Güvenlik Mühendisliği

## Alan: Ne ile ilgilenir?

Burada amaç yalnızca mevcut saldırıları tespit etmek değil, güvenliği sistemin mimarisine yerleştirmektir.

## Günlük olarak neler yapabilir?

Bir güvenlik mühendisi:

* Güvenlik mimarileri tasarlayabilir.
* Güvenlik araçlarını kurabilir.
* Firewall ve güvenlik sistemlerini yapılandırabilir.
* IAM sistemlerini tasarlayabilir.
* Network segmentation uygulayabilir.
* Güvenlik otomasyonları geliştirebilir.
* Cloud güvenlik kontrolleri oluşturabilir.
* Güvenlik standartlarını uygulayabilir.

## Hangi teknik bilgilere ihtiyaç duyar?

* Network
* Operating systems
* Cloud
* IAM
* Cryptography
* Security architecture
* Automation
* Scripting
* Infrastructure
* DevSecOps

### Kısaca

> **Security Engineering = Güvenliği sistemlerin tasarımına ve altyapısına yerleştirmek.**

# 📝 Kendi Öğrenme Notlarım

Bu bölümden öğrendiğim en önemli şey:

> **Siber güvenlik tek bir meslek değildir. Birçok farklı uzmanlık alanından oluşur.**

Örneğin:

* Ağları seviyorsam → **Network Security**
* Log ve olay analizini seviyorsam → **SOC / Blue Team**
* Sistemlerin güvenliğini saldırgan gibi değerlendirmek ilgimi çekiyorsa → **Pentest**
* Web uygulamaları ilgimi çekiyorsa → **Web Security**
* Mobil uygulamalar ilgimi çekiyorsa → **Mobile Security**
* Dijital deliller ilgimi çekiyorsa → **Digital Forensics**
* Zararlı yazılımların nasıl çalıştığını merak ediyorsam → **Malware Analysis**
* Cloud altyapıları ilgimi çekiyorsa → **Cloud Security**
* Yazılım geliştirme ile güvenliği birleştirmek istiyorsam → **Application Security**
* Gerçek güvenlik olaylarını araştırmak ilgimi çekiyorsa → **Incident Response**
* Tehditleri ve saldırgan davranışlarını araştırmak ilgimi çekiyorsa → **Threat Intelligence**
* Sistemlerin güvenli mimarisini oluşturmak ilgimi çekiyorsa → **Security Engineering**

Bu alanların çoğu birbirleriyle bağlantılıdır ve ortak temel bilgiler gerektirir.
